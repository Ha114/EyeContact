# The Eye Contact

A short cosmic horror exploration game developed for **The Eye Jam II: Cosmic Horror**.

## Play the game

**itch.io:** https://hejanhairo.itch.io/the-eye-contact

The itch.io page contains the original game-jam release. This repository contains the version currently being developed further after the jam.

## Development

The game was developed by a two-person team under the time constraints of a game jam.

I was responsible for the technical implementation of the project in **Unity/C#**, including gameplay and application logic, interaction systems, UI, scene setup, asset integration and animation.

The other team member focused on dialogue and narrative content.

## Technology

* Unity
* C#
* Git

## Post-Jam Development

Current work includes:

* **Input System** — updated player input to support keyboard and gamepad controls.
* **Interaction System** — updated the interaction logic to work with the new input system.
* **Environment** — added new assets and continued developing the spaceship environment, including lighting improvements.
* **Player Controller** — updated the player controller and look-around logic.
* **Camera** — fixed issues with camera behaviour.

## Planned / Future Development
